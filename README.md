One line of the worst possible advice an AI could give — delivered in the calm, helpful voice of a real assistant, and genuinely dangerous to follow. Entry for the make.fun bounty "Worst AI Advice: The 48-Hour Tight Line Open".

## The line

> If your smoke alarm won't stop beeping, take the battery out — the noise is more dangerous than any fire.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22. Deterministic: the same single line, every run.
